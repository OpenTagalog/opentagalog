# Contributing to OpenTagalog

Thank you for your interest in contributing to **OpenTagalog**!

Our mission is to build the world's best free, open-source platform for learning Tagalog. Whether you're a native speaker, a language learner, a developer, a teacher, or simply someone who wants to help, your contribution is welcome.

---

# Project Goals

OpenTagalog aims to provide:

* A complete structured Tagalog course.
* A searchable English ↔ Tagalog dictionary.
* A comprehensive Tagalog grammar reference.
* High-quality educational content.
* A modern, accessible, and mobile-friendly learning experience.
* A completely free and open educational resource.

# Ways to Contribute

We welcome contributions in many areas, including:

* New course lessons
* Dictionary entries
* Grammar explanations
* Native speaker audio recordings
* Bug fixes
* Documentation
* User interface improvements
* Accessibility improvements
* Performance improvements
* Tests
* Typo corrections
* Translations

No contribution is too small.

---

# Lesson Guidelines

Each lesson should:

* Teach one primary topic.
* Build naturally upon previous lessons.
* Include practical real-world examples.
* Introduce vocabulary gradually.
* Explain new grammar clearly.
* Include exercises where appropriate.
* Include a short review or quiz.
* Remain beginner-friendly unless intended for higher levels.

Lessons should follow the project's lesson template and writing style.

---

# Dictionary Guidelines

Dictionary entries should include, where appropriate:

* Tagalog word
* English translation
* Part of speech
* Pronunciation
* Example sentence
* English translation of the example
* Related words
* Notes on usage
* Audio pronunciation (when available)

---

# Grammar Guidelines

Grammar pages should:

* Explain one concept at a time.
* Include multiple examples.
* Explain common learner mistakes.
* Link to related lessons.
* Link to relevant dictionary entries.
* Prefer clear explanations over technical linguistic terminology whenever possible.

---

# Native Speaker Review

Whenever possible, educational content should be reviewed by a fluent or native Tagalog speaker before being considered complete.

This is especially important for:

* Example sentences
* Natural expressions
* Idioms
* Pronunciation guidance
* Cultural explanations

Suggestions and corrections from native speakers are highly appreciated.

---

# Sources and References

If your contribution is based on books, academic publications, official language resources, or other educational material, please cite your sources whenever practical.

Reliable references help maintain consistency and improve the long-term quality of the project.

---

# Writing Style

Please follow the project's `docs/style-guide.md`.

This helps ensure that:

* Lessons follow a consistent structure.
* Grammar terminology remains consistent.
* Vocabulary formatting is uniform.
* Learners have a predictable experience throughout the course.

---

# Code Guidelines

Please:

* Keep components reusable.
* Avoid duplicate code.
* Follow the existing project structure.
* Prefer readability over cleverness.
* Keep functions small and focused.
* Document non-obvious code.
* Write maintainable code that future contributors can easily understand.

---

# Accessibility

OpenTagalog strives to be accessible to everyone.

Please:

* Use semantic HTML.
* Add descriptive alt text to images.
* Use meaningful button labels.
* Ensure keyboard accessibility.
* Maintain sufficient color contrast.
* Avoid relying solely on color to communicate information.

---

# Reporting Bugs

When reporting a bug, please include:

* Steps to reproduce the issue.
* Expected behavior.
* Actual behavior.
* Browser and operating system.
* Screenshots or screen recordings if helpful.

---

# Feature Requests

Feature requests are welcome.

Please describe:

* The problem you are trying to solve.
* Your proposed solution.
* Possible alternatives you considered.
* Any additional context that may be useful.

---

# Pull Requests

Before submitting a pull request:

* Ensure your changes work correctly.
* Keep pull requests focused on a single topic.
* Update documentation when necessary.
* Resolve merge conflicts.
* Be open to feedback during code review.

---

# Community

Please be respectful, patient, and constructive.

OpenTagalog welcomes contributors of all backgrounds and experience levels.

We value:

* Accuracy
* Collaboration
* Kindness
* Respect
* Curiosity
* Continuous learning

Everyone started somewhere, and we believe that learning and teaching are best achieved together.
