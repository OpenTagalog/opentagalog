# OpenTagalog Roadmap

## Vision

OpenTagalog is a free, open-source platform for learning Tagalog from beginner to advanced level.

The platform consists of three integrated parts:

1. Course
   - Approximately 180 structured lessons.
   - Vocabulary.
   - Audio pronunciation.
   - Interactive quizzes.
   - Progress tracking.

2. Dictionary
   - English ↔ Tagalog.
   - Example sentences.
   - Pronunciation.
   - Audio.
   - Related words.

3. Grammar Reference
   - Complete grammar explanations.
   - Searchable by topic.
   - Cross-linked from lessons and dictionary entries.

## Design Goals

- Free forever.
- Open source.
- Mobile friendly.
- Fast.
- Accessible.
- Easy to contribute to.
- Lessons remain content-only.
- UI is built from reusable Astro components.

## Future Features

- Native speaker audio.
- Flashcards.
- Spaced repetition.
- User accounts (optional).
- Progress tracking.
- Printable worksheets.
- Downloadable PDFs.
- Dark mode.
