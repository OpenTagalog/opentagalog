# Open Tagalog

Open Tagalog is an Open Educational Resource (OER).

> **Making Tagalog accessible to everyone, everywhere.**

A free and open educational platform for learning Tagalog.

---

# About Open Tagalog

Open Tagalog is a long-term open education project dedicated to creating the world's most comprehensive, professionally structured, and freely available Tagalog course for English speakers.

The project aims to provide a complete learning ecosystem from absolute beginner (A0) to independent user (B2), including lessons, textbooks, workbooks, grammar references, vocabulary resources, audio materials, and interactive learning tools.

---

# Why Open Tagalog?

Learning a language should not depend on expensive subscriptions or limited access to educational materials.

Many learners around the world want to learn Tagalog but struggle to find resources that are:

* Complete
* Structured
* Affordable
* Professionally designed
* Freely accessible

Open Tagalog exists to remove those barriers.

# Project Principles

Open Tagalog follows these principles:

* **Learner first** — When in doubt, optimize for the learner.
* **Open by design** — Educational knowledge should remain accessible.
* **Single source of truth** — Content should be created once and reused everywhere.
* **Automation first** — Repetitive processes should be automated whenever practical.
* **Long-term thinking** — Every major decision should still make sense ten years from now.
